## Headline findings

**L3 — shipped broken by both B runs; triggered a real engine improvement.** Both
sonnet-B and opus-B left the `approve` form + phantom `reject` route unreconciled.
The gate was exercised but with a conforming `approve` decision, so the
`decision_rejected` path was never hit. The finding was forwarded to the engine
team; the `gate-route-not-in-form` lint was added as a hard validate error. L3 is
now a lint-rescued trap (surfacing order: first, at `yaah validate`).

**L2 — found vestigial; trap re-seeded this round.** Opus-B identified that the
loop-guidance line in `draft.md` read `{{loop_feedback}}` correctly (matching what
`tally` writes), so the documented "blind-retry" trap did not exist. The "decoy"
call was correct: the answer-key's L2 was measuring nothing. Re-seeded this round:
`draft.md` now reads `{{?judge_notes}}` (a key `tally` never writes), so the loop
guidance renders empty on every pass-2+ without lint and without fault.

**Doc bugs surfaced and fixed:**
- "classify branches, lists cycle" — answer-key claimed classify had a loop;
  it does not. Fixed.
- Flat-key `{{key}}` placeholder reads in `agent.ask` and render templates were
  undocumented. Fixed in docs.
- Wheel-missing setup instructions — `pip install -e` worked but wheel build docs
  were absent. Folded into the yaah manual.
- Gate `allow_untrusted` asymmetry in the schema — documented and fixed.

## Trial-integrity findings

**Sonnet-A read `answer-key.md` mid-trial** (transcript-verified file path). The
run's Part-A successes are discounted; its friction log is retained as qualitative
data. Root cause: `pip install -e` put the repo on `sys.path`, making the kit dir
reachable by relative path. Isolation hardened this round: non-editable installs
required; builder brief now states out-of-bounds rule explicitly; "read answer key"
added as an invalidating red-flag event.

**Heavy engine-source reads:** opus read engine source across ~4 clusters; sonnet
across ~6 in Part A. Some reads were through the editable install (`src/yaah/`
path); others through site-packages. Non-editable install will distinguish these
in round 2 — repo-tree reads become impossible; site-packages reads remain
detectable by path.

**State-dir deletions:** both runs had at least one `rm -rf state` or equivalent.
All were benign (no live baton was in flight) but noted as a red flag — the
parked-gate model was not immediately obvious to either builder.
